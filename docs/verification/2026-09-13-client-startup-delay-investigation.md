# Задержка входа: клиентский autoprobe и шлюз

Историческая локальная диагностика 2026-09-13, публичная сокращённая версия.
Речь о входе на сервер после выбора, а не о времени запуска окна клиента.

В исследованном профиле Q2PRO-X были включены `cl_net_clientport_autoprobe=1`,
`cl_net_clientport_autoprobe_ports=6`, `cl_net_clientport_autoprobe_time=68.5`.
Режим пробовал дополнительные UDP source ports до основного подключения.
Шлюз привязывает endpoint к первому источнику; другие источники могут быть
отклонены. Это несовместимо с ожиданием клиентского autoprobe.

Контролируемое локальное воспроизведение дало около 68.527 с ожидания
с autoprobe и около 0.005 с без него. Это измерение локального механизма,
а не времени входа на живой Dos.Zone сервер и не гарантия для любой версии Q2PRO-X.

В исследованном профиле применялось `set cl_net_clientport_autoprobe "0"`.
Это локальное изменение CFG, не исправление шлюза и не настройка, которую
add-on автоматически применяет всем пользователям. Add-on CFG игры не редактирует.
Изменение source-port политики шлюза потребовало бы отдельной проверки изоляции.
