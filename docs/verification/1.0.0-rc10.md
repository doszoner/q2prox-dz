## Граница утверждений

Пройденная проверка exact клиента подтверждает, что Q2PRO-X умеет получать
пустой и изменяющийся локальный HTTP-источник через обычный `Custom` и может
использовать один UDP source для последовательности `status`/`connect`.
Она не подтверждает работоспособность текущих rc10 launcher/coordinator,
переход между двумя реальными комнатами, закрытие комнаты, ресурсы или
пользовательские архивы.

Пока строки живого перехода между комнатами не закрыты, rc10 остаётся
кандидатом закрытой альфы. Q2PRO-X, Q2PRO-X CFG, Favorites, карты и PAK-файлы
в этот проект не входят.

Именно закрытая альфа является текущей точкой передачи. Автоматизация создания
и закрытия публичных комнат не используется как дополнительный выпускной
барьер: переходы `A -> B`, движение/стрельба и поведение на компьютерах
пользователей проверяются тест-группой по строкам `PENDING` выше. До получения
этих свидетельств кандидат нельзя переименовывать в публичный выпуск.
