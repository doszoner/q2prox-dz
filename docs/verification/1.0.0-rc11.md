# q2prox-dz 1.0.0-rc11: verification

Дата: 2026-08-30

Документ ведётся fail-closed. `PASS` означает проверку именно исходников или
архивов rc11; результаты rc10 ниже используются только как исходное живое
свидетельство неизменённого transport/lifecycle пути.

## Причина выпуска

При запуске с пустым локальным источником exact Q2PRO-X 1.5 команда
`serverbrowser_open_modern` оставляла чёрный экран. `Esc` и открытие консоли
переключали частично отрисованный белый прямоугольник, но не возвращали рабочее
меню. HTTP source при этом отвечал корректно: `200 OK`, `Content-Length: 0`.

Последовательные A/B-проверки показали:

- обычный Q2PRO-X — рабочее меню;
- `+set game 3zb2` — рабочее меню;
- другой Wine prefix — дефект сохраняется;
- задержка перед `serverbrowser_open_modern` и `serverbrowser_refresh` — дефект
  сохраняется;
- тот же пустой HTTP source без `serverbrowser_open_modern` — рабочее меню,
  рабочий переход `Join online` → `Custom` и возврат по `Esc`.

Исправление удаляет только принудительный автозапуск браузера на Linux и
Windows. Координатор не передаёт команду управления меню: Q2PRO-X использует
свою обычную настройку запуска. Локальный source, gateways, каталог, transport
и room lifecycle не изменены. Q2PRO-X также получает непостоянный
`cl_timeout 20`, чтобы закрытая комната не оставляла клиента на стандартном
120-секундном ожидании.

## Сохранённое живое свидетельство transport

Перед rc11 на установленном rc10 выполнен переход Room A → Room B в одном
процессе Q2PRO-X PID `2886884`, start time `2026-08-30 10:26:51`:

- Room A: protocol 35, `The Edge`, вход игрока, движение и стрельба;
- закрытие A: `GATEWAY_ROOM_CLOSED`, `HUB_GATEWAY_STOP reason=room-closed`,
  Q2PRO-X остался жив;
- Room B: тот же PID, protocol 35, `Tokay's Towers`, вход игрока;
- закрытие B остановило только её gateway;
- штатный выход Q2 завершил coordinator и удалил owned session state.

Это подтверждает transport и A→B lifecycle, которые rc11 не меняет. Оно не
заменяет живые Windows gates, оставленные `PENDING` выше.

## Вердикт

До закрытия строк `PENDING` rc11 является кандидатом закрытой альфы. Windows
архивы остаются неподписанными; Authenticode нужен для широкого публичного
распространения, но не для ограниченной тест-группы после correctness gates.
