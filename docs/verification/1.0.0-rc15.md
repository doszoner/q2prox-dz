# Проверка 1.0.0-rc15

Purpose: record the correction release after the Linux shared-gateway
capacity/liveness blocker found during rc14 verification.

## Scope

`1.0.0-rc15` changes the Linux native shared gateway and fixes a Windows
lifecycle-matrix test race. Windows runtime code is rebuilt but otherwise
unchanged from the rc14 shared-gateway implementation.

## Fixed blocker

During rc14 controlled checks, the Linux shared gateway could leave a target in
an intermediate state: the target was counted in `targets=N`, but did not reach
`READY` and did not emit `FAILED`/`CLOSED`.

The root cause was readiness-probe send-result handling. HumbleNet/WebRTC-NET
may return `0` while a connection is still being established. For a target that
already has a concrete peer, a short or zero send means the OOB readiness probe
was not delivered. The old code treated that as neither success nor failure.

The rc15 gateway now treats full-size send as delivered and any short/zero send
for a concrete peer as a bounded probe miss. After the existing failure budget,
the target closes with `CLOSED reason=probe_timeout` instead of hanging
silently.
