# 1.0.0-rc18 — Linux candidate, Windows pending

Дата: 2026-10-18. VERSION: `1.0.0-rc18`.

## Исходники и статус

Release source SHA будет взят из отдельного metadata commit до сборки и
зафиксирован в tag/release notes. Linux собирается из чистого `git archive`
этого commit; Windows должен использовать тот же commit и VERSION.
Исторические rc17 не являются входными поставками rc18.

## Windows и публикация

[Windows handoff](2026-10-18-nearest-turn-windows-handoff.md) сохраняет
component/live checklist и инструкции source launcher. Человек собирает только
Windows из release SHA, добавляет portable/setup и sidecars в существующий
Draft rc18, затем комплектует общий alpha с уже готовым Linux.
Unsigned Windows ограничен закрытой alpha; для широкого выпуска обязательны
Authenticode и exact archive gates из [RELEASE.md](../RELEASE.md).
Ни Windows PASS, ни защита общей TURN-квоты, ни публичная/latest публикация
этой Linux-сборкой не подтверждаются.
