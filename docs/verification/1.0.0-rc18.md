## Windows и границы выпуска

[Windows handoff](2026-10-18-nearest-turn-windows-handoff.md) сохраняет
Windows PowerShell 5.1 component/live checklist и инструкции source launcher.
Человек собирает только Windows из SHA выше с locked dependencies, добавляет
portable/setup и `.sha256` в существующий Draft rc18, затем комплектует общий
alpha с уже готовым Linux. Никакие фактические Windows hashes или PASS здесь
не заявлены. Unsigned Windows ограничен закрытой alpha; для широкого выпуска
обязательны Authenticode и exact archive gates из [RELEASE.md](../RELEASE.md).

Linux nearest-TURN live был проверен **ранее из исходников**; это не gameplay
приёмка нового архива. Этот результат подтверждает Linux package/build gates
и оставляет поставку **candidate**. Ни Windows PASS, ни защита общей TURN-квоты,
ни публичная/latest публикация этой Linux-сборкой не подтверждаются.
