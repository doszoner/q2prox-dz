# Проверка 1.0.0-rc13

`1.0.0-rc13` добавляет совместимые `q2ded`-серверы во встроенный список
`Custom` Q2PRO-X. Этот файл отделяет выполненные проверки от оставшихся
release-gates; отсутствие строки `PASS` нельзя трактовать как успех.

## Выполнено

- 2026-09-03: текущая публичная форма `q2ded`, exact lookup и RTC schema —
  PASS; подробности без учётных данных находятся в
  [q2ded compatibility preflight](2026-09-03-q2ded-compatibility-preflight.md).
- Linux catalog/launcher tests: PASS, 50 tests.
- Windows shared catalog contract: PASS, 25 cases.
- Windows launcher stdin contract: PASS.
- Linux coordinator portable CTest: PASS, 4/4.
- Windows coordinator portable core CTest: PASS, 2/2.

## Не выполнено

- Linux package из чистой распаковки и живой вход в `q2ded`.
- Живое переключение `q2ded` → `q2` без завершения Q2PRO-X.
- Пять одновременно готовых endpoint и 60-секундный замер ресурсов Linux.
- Exact MSVC build, lifecycle matrix, portable/setup package и живой Windows
  вход.
- Пять WebView2 gateway trees и 60-секундный замер ресурсов Windows.
- Проверка готовых архивов, SHA-256 и отсутствие orphan/session data.

До заполнения этих пунктов rc13 остаётся кандидатом и не является готовой
пользовательской поставкой.
