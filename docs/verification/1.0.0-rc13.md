# Проверка 1.0.0-rc13

`1.0.0-rc13` добавляет совместимые `q2ded`-серверы во встроенный список
`Custom` Q2PRO-X. Этот файл отделяет выполненные проверки от оставшихся
release-gates; отсутствие строки `PASS` нельзя трактовать как успех.

## Выполнено

- 2026-09-03: текущая публичная форма `q2ded`, exact lookup и RTC schema —
  PASS; подробности без учётных данных находятся в
  [q2ded compatibility preflight](2026-09-03-q2ded-compatibility-preflight.md).
- Linux catalog/launcher tests: PASS, 50 tests.
- Windows shared catalog contract: PASS, 25 cases.
- Windows launcher stdin contract: PASS.
- Linux coordinator portable CTest: PASS, 4/4.
- Windows coordinator portable core CTest: PASS, 2/2.
- Linux locked release build: PASS, 5/5 CTest plus security invariants.
- Linux sanitizer build: PASS, 4/4.
- Linux reproducible build: PASS.
- Linux package install/update/uninstall smoke: PASS.
- Локальная установка поверх rc10, удаление и повторная установка rc13: PASS;
  сохранённый путь к Q2PRO-X не удалён.
- Живой каталог на Linux: три `q2ded` и одна доступная `q2` строка подняли
  четыре независимых gateway; все четыре вернули настоящий Quake II `status`.
- 60 секунд, четыре idle gateway плюс coordinator/guardian, Q2PRO-X исключён:
  median CPU 6.4% одного логического ядра, max 6.8%, median/max RSS 117.7 MiB,
  threads 27 без роста. После owner stop процессов и session directories не
  осталось.

## Не выполнено

- Живой вход в карту `q2ded`, движение/выстрел и переключение на `q2`: ввод в
  GUI не выполнялся; системный запрос KDE не был принят автоматически.
- Живое переключение `q2ded` → `q2` без завершения Q2PRO-X.
- Пять одновременно готовых endpoint: во время проверки каталог содержал
  только четыре совместимых строки; 60-секундный замер выполнен для четырёх.
- Exact MSVC build, lifecycle matrix, portable/setup package и живой Windows
  вход.
- Пять WebView2 gateway trees и 60-секундный замер ресурсов Windows.
- Проверка готовых архивов, SHA-256 и отсутствие orphan/session data.

До заполнения этих пунктов rc13 остаётся кандидатом и не является готовой
пользовательской поставкой.
