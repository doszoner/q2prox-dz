  ELF hardening и gateway contract PASS.

  release build; затем fresh-extract install/update/uninstall smoke PASS.

Первый запуск `check-reproducible.sh` обнаружил старую ошибку его изолированного
copy: копируется только `linux/`, а CMake с тестами требует
`../tests/tools/q2dz-controlled-peer.cpp`. Коммит `b4a9fae` задаёт
`BUILD_TESTING=OFF` только для двух production-сборок сравнения. Полные тесты
остались включены и прошли отдельно в sanitizer/release gates. После этой
однострочной правки воспроизводимость прошла; sanitizers повторно не запускались.
