# Число участников лобби и игроков на сервере

Публичная сводка исследования 2026-08-29. Исторические данные комнат и
идентификаторы удалены; новые сетевые проверки при переносе не выполнялись.

Участники комнаты Dos.Zone и игроки внутри Quake II — разные множества.
Browser peer может присутствовать в лобби без игрового подключения; native
Q2PRO-X через gateway не обязан иметь отдельную браузерную запись лобби.
Нельзя подменять серверный player list значением `connected_peers` каталога.

Для игрового server browser источник — настоящий ответ Quake II `status`
через транспорт; каталог нужен для обнаружения и сопоставления комнаты.
Это согласуется с [ADR 0004](../adr/0004-q2pro-x-custom-source-room-hub.md):
шлюз не должен синтезировать фиктивный server status из метаданных лобби.
