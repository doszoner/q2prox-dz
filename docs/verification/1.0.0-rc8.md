## Windows A/B/C evidence

The host room was kept in an OS-foreground browser window for all variants so
server-side browser throttling could not confound the client gateway result.
Only bounded numeric counters were retained; packet contents, room JSON,
credentials, ICE, SDP, cookies and tokens were not logged.

Representative steady-state results:

| Variant | WebView2 state | Timer ticks / 1 s | Timer max gap | WebRTC→UDP max gap | Result |
|---|---|---:|---:|---:|---|
| A | invisible, no flags | 2–4 | 979–1025 ms | ~984–1032 ms | Reproduced 1 Hz |
| B | invisible, one diagnostic timer flag | 113–137 | 14–34 ms | ~110–125 ms | Smooth |
| C | visible, no flags | 151–172 | 14–28 ms | ~110–125 ms | Smooth; selected |

All three retained shutdown summaries reported zero oversized or invalid
cadence drops and the coordinator reported zero managed processes after exit.
The exact local evidence directory is intentionally outside the public repo:

```text
<local-evidence-root>/20260824T052846Z-final-live
```

The C diagnostic binary was a one-line source variant of A. Its old hard-coded
diagnostic label still printed `controller_visible=false`; the retained diff
and source SHA prove that its actual `put_IsVisible` argument was `TRUE`.
The rc8 production source removes that ambiguity by logging the shared
`controller_visible` constant.

## Exact package evidence

The Windows VM used Windows 11 build 26100.9168 with 4 vCPU and 8 GiB RAM. The
basic software renderer was a VM-only render constraint; B, C and the exact rc8
portable/setup sessions retained normal transport cadence under the same
guest. The setup end-state was measured as:

```text
installed:   current=true  versions=1 q2Path=true shortcut=true  managed=0
uninstalled: current=false versions=0 q2Path=true shortcut=false managed=0
```

The Linux exact-package session reached `TRANSPORT_READY`, connected with
protocol 35, entered `q2dm1`, emitted the test chat `LINUX-LIVE`, and ended with:

```text
SESSION_CLOSED reason=q2-normal-exit
oversized_udp_drops=0 oversized_transport_drops=0
```

Raw screenshots, command lines and room-specific evidence remain outside the
public repository. Only this redacted result and content hashes are public.
