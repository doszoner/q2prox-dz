# Спецификации q2prox-dz

Канонические редактируемые пакеты проекта перенесены сюда из общего рабочего
каталога DosZone 2026-10-18. В общем каталоге оставлены локальные ссылки на
эти пакеты. OpenSpec CLI не перечисляет такие symlink-каталоги из общего
workspace: команды выполнять из корня `q2prox-dz`, а не `DosZone`.
Они не входят в пользовательские бинарные архивы.

| Change | Состояние по `36e0663` | Что остаётся |
| --- | --- | --- |
| [fix-q2prox-rooms-vanish](changes/fix-q2prox-rooms-vanish/proposal.md) | Logging и tolerant rows реализованы в исходниках после rc17 | Recovery группы D условный и не реализован; старые отметки проверок не являются новой приёмкой |
| [q2prox-nearest-turn](changes/q2prox-nearest-turn/proposal.md) | Предложение, код не изменён | Выбор ICE на обеих ОС; последующее ограничение соединений отдельно |

Delta specs внутри `changes/` содержат также ещё не реализованные требования.
Не переносить их целиком в базовые specs и не архивировать change как завершённый.
Текущий контракт описан в [архитектуре](../docs/ARCHITECTURE.md),
[ADR 0004](../docs/adr/0004-q2pro-x-custom-source-room-hub.md) и [LOGGING.md](../docs/LOGGING.md).

Для ближайших RTC-серверов исправлены недоказанные расчёты аллокаций,
позиционный выбор TURN-записи и неограниченное ожидание DNS. Полная задача
защиты ресурса описана в [TURN resource policy](../docs/TURN-RESOURCE-POLICY.md).

Проверка формата из корня репозитория: `openspec validate --all --strict --no-interactive`.
Она проверяет документы, не реализацию и не gameplay.
