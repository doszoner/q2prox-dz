# Установка q2prox-dz

Add-on подключает уже установленный Q2PRO-X к существующим публичным комнатам
Quake II на Dos.Zone. Игра и игровые данные поставляются отдельно.

## Если Q2PRO-X ещё не установлен

Скачайте последнюю версию с официального сайта <https://q2pro-x.com/>,
распакуйте её, добавьте принадлежащие вам данные Quake II и один раз запустите
клиент. При обновлении Q2PRO-X используйте тот же официальный источник.

## Windows setup

1. Скачайте `q2prox-dz-1.0.0-rc8-windows-x64-setup.zip` и полностью распакуйте его.
2. Закройте Q2PRO-X и запустите `Install.cmd`.
3. При первом запуске укажите `Q2PRO-X.exe`.
4. Откройте **Q2PRO-X - Dos.Zone** из меню «Пуск», выберите комнату и нажмите
   `Join`.

Права администратора не нужны. Повторный запуск нового `Install.cmd` обновляет
add-on. Для удаления используйте ярлык **Uninstall Q2PRO-X - Dos.Zone**.

## Windows portable

1. Скачайте `q2prox-dz-1.0.0-rc8-windows-x64-portable.zip` и распакуйте его в
   отдельную папку.
2. Закройте Q2PRO-X и запустите `Run.cmd`.
3. При первом запуске укажите `Q2PRO-X.exe`, выберите комнату и нажмите `Join`.

Для обновления распакуйте новый архив в новую папку. Для удаления удалите эту
папку. Сохранённый путь к Q2PRO-X находится в
`%LOCALAPPDATA%\Q2PRO-X Dos.Zone\state\q2-path.txt`; его можно удалить отдельно.

Если Windows сообщает об отсутствии WebView2 Runtime, установите официальный
Microsoft Evergreen Runtime x64:
<https://developer.microsoft.com/microsoft-edge/webview2/consumer/>.

## Linux x86-64

Нужны Wine, Python 3 и библиотеки, перечисленные в
[linux/README.md](linux/README.md).

```bash
tar -xzf q2prox-dz-1.0.0-rc8-linux-x86_64.tar.gz
cd q2prox-dz-1.0.0-rc8
./install.sh
```

Запустите **Q2PRO-X — Dos.Zone** из меню приложений или командой
`q2dz-launch`. Повторный `./install.sh` обновляет add-on. Удаление:

```bash
"${XDG_DATA_HOME:-$HOME/.local/share}/q2dz/uninstall.sh"
```

## Если Q2PRO-X обновлён или перенесён

Если путь к EXE не изменился, ничего делать не нужно. Если изменился:

- Windows: удалите `%LOCALAPPDATA%\Q2PRO-X Dos.Zone\state\q2-path.txt` и снова
  запустите launcher;
- Linux: выполните `q2dz-launch --select-q2`.

## Типичные проблемы

- **Комнат нет:** сейчас нет готовых публичных комнат; попробуйте позже.
- **Комната закрылась:** вернитесь к списку и выберите актуальную.
- **Q2PRO-X уже запущен:** закройте его перед `Join`.
- **Map ... is missing:** установите нужную карту/мод из доверенного источника
  в выбранную игровую установку либо выберите другую комнату.
- **Unknown publisher:** Windows RC пока не подписан. Для закрытого alpha-теста
  используйте GitHub Release либо архив от доверенного распространителя с
  проверенным SHA-256; для широкого публичного распространения требуется
  Authenticode.

Комнату создают в официальном интерфейсе Dos.Zone. После создания перезапустите
launcher, чтобы обновить список.

## Необязательная проверка архива

Рядом с каждым release-архивом публикуется файл `.sha256`. Проверка особенно
полезна при передаче архива не через GitHub:

```powershell
Get-FileHash .\q2prox-dz-*-windows-x64-*.zip -Algorithm SHA256
```

```bash
sha256sum -c q2prox-dz-*-linux-x86_64.tar.gz.sha256
```
