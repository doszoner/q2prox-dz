Q2PRO-X - Dos.Zone Portable для Windows
=======================================

Portable-вариант не устанавливается и не создаёт ярлыки: распакуйте его и
запускайте Run.cmd. Он использует тот же gateway и launcher, что setup-вариант.
Игра, карты, PAK и CFG не заменяются.

Что понадобится
---------------

- Windows 10/11 x64;
- Microsoft Edge WebView2 Runtime;
- установленный Q2PRO-X.exe и легальные игровые данные Quake II;
- доступ в Интернет.

Если Q2PRO-X ещё не установлен
------------------------------

Скачайте актуальный Q2PRO-X с официальной страницы:
https://q2pro-x.com/

Скачайте последнюю опубликованную версию. Распакуйте её по инструкции проекта
в отдельную игровую папку, добавьте принадлежащие вам игровые данные и один раз
запустите Q2PRO-X.exe. Add-on сам игру не скачивает и не обновляет.

Если отсутствует WebView2 Runtime, установите официальный Microsoft Evergreen
Runtime для x64:
https://developer.microsoft.com/microsoft-edge/webview2/consumer/

Первый запуск
-------------

1. Полностью распакуйте ZIP в обычную доступную для записи папку. Не запускайте
   Run.cmd внутри ZIP.
2. Закройте уже запущенный Q2PRO-X.
3. Дважды щёлкните Run.cmd.
4. Укажите существующий Q2PRO-X.exe.
5. Выберите живую комнату и нажмите Join.

Папку portable можно держать отдельно от Q2PRO-X. Add-on запоминает только путь
к выбранному EXE в профиле текущего пользователя.

Обновление
----------

- Q2PRO-X: обновляйте отдельно по инструкции q2pro-x.com. Если путь к
  Q2PRO-X.exe не изменился, add-on перенастраивать не нужно.
- Add-on: закройте Q2PRO-X и launcher, распакуйте новый portable ZIP в новую
  папку и запускайте новый Run.cmd. Старую portable-папку после этого можно
  удалить.

Если Q2PRO-X перенесён или выбран не тот EXE
-------------------------------------------

Закройте launcher и удалите только файл:

%LOCALAPPDATA%\Q2PRO-X Dos.Zone\state\q2-path.txt

При следующем Run.cmd launcher снова предложит выбрать Q2PRO-X.exe.

Типичные ситуации
-----------------

- «Close the running Q2PRO-X»: закройте обычный Q2PRO-X и повторите Join.
- Комнат нет: сейчас нет готовых публичных комнат; закройте и снова запустите
  Run.cmd позднее.
- Комната закрылась или устарела: вернитесь к списку и выберите актуальную.
- «Map ... is missing»: нужной карты нет в выбранной установке Q2PRO-X.
  Установите карту/мод из доверенного источника в эту игровую установку либо
  выберите комнату с уже имеющимся контентом.
- Ошибка WebView2: установите или восстановите Microsoft WebView2 Runtime по
  ссылке выше, затем повторите запуск.
- Windows показывает Unknown publisher: этот RC не подписан. Запускайте архив
  из GitHub Release либо полученный от доверенного распространителя вместе с
  опубликованным SHA-256.

При передаче архива не через GitHub его можно дополнительно проверить по
приложенному файлу .sha256 командой PowerShell Get-FileHash.

Создание комнаты выполняется в официальном браузерном интерфейсе Dos.Zone.
После создания снова запустите Run.cmd, чтобы обновить список.

Удаление
--------

Удалите распакованную portable-папку. Чтобы также забыть выбранный путь и
удалить временное состояние add-on, удалите:

%LOCALAPPDATA%\Q2PRO-X Dos.Zone

Q2PRO-X, игровые данные, PAK и CFG при этом не затрагиваются.
