# q2prox-dz

`q2prox-dz` подключает уже установленный **Q2PRO-X** к публичным комнатам
Quake II на Dos.Zone. Add-on получает каталог комнат, поднимает локальный
UDP↔WebRTC шлюз для каждой выбранной комнаты и запускает неизменённый Q2PRO-X.

Add-on не содержит Quake II, Q2PRO-X, карты или PAK-файлы; add-on сам не
редактирует CFG игры и не требует от пользователя ручной правки CFG. Обычный
Q2PRO-X может автоматически сохранить несекретный loopback source по своему
штатному поведению (см. [ADR 0004](docs/adr/0004-q2pro-x-custom-source-room-hub.md)).
Комнаты создаются в обычном интерфейсе Dos.Zone.

## Установка

Скачайте подходящий архив со страницы GitHub Releases:

- Windows x64 setup — установка с ярлыком в меню «Пуск»;
- Windows x64 portable — распаковка без установки;
- Linux x86-64 — пользовательская установка, Q2PRO-X запускается через Wine.

Полные инструкции: [INSTALLATION.md](INSTALLATION.md).

## Требуемый Q2PRO-X

Поддерживаемый профиль — Q2PRO-X 1.5 by ly, сборка 2026-08-25, или точно
совместимая с ней сборка. Произвольные Quake II forks и другие игры Dos.Zone
этим add-on не поддерживаются.

Если Q2PRO-X отсутствует или устарел:

1. Скачайте выпуск 1.5 с [официальной страницы Q2PRO-X](https://q2pro-x.com/).
2. Распакуйте или установите Q2PRO-X рядом с вашим контентом Quake II
   (`baseq2`, `3zb2` и принадлежащие вам PAK-файлы).
3. При первом запуске add-on укажите установленный `Q2PRO-X.exe`.

При обновлении заменяйте файлы самого Q2PRO-X по инструкции upstream-выпуска.
Q2PRO-X и его игровые данные поставляются отдельно от этого проекта.

## Как это работает

```text
Dos.Zone room catalog
        ↓
q2prox-dz launcher → local managed gateway → WebRTC → Dos.Zone room
        ↓                         ↑
Q2PRO-X ───── UDP 127.0.0.1 ─────┘
```

Windows использует WebView2, Linux — нативный WebRTC-NET transport. Launcher
запускает Q2PRO-X один раз и поддерживает до двух комнат в штатной вкладке
`Custom`. Отдельного окна выбора нет; add-on не редактирует CFG и Favorites.
Пользователю не нужно редактировать CFG, Favorites или аргументы запуска.

После запуска launcher не переключает меню Q2PRO-X принудительно: клиент
использует обычную настройку стартового меню. Если видна консоль, нажмите
`Esc`, откройте `Join online` → `Custom` и нажмите `Refresh`.

Каталог опрашивается примерно раз в 15 секунд. Новая комната становится видна
после очередного успешного опроса и обычного `Refresh` в `Custom`; закрытая —
после двух успешных опросов, в которых её уже нет. Q2PRO-X перезапускать не
нужно. Заполненная активная комната сохраняется, а третья комната не вытесняет
уже выбранные две. Ошибка каталога не очищает текущие комнаты.

## Состояние

`1.0.0-rc12` — Windows hotfix для живого двухслотового источника `Custom`. Точный
контракт Q2PRO-X для локального HTTP-источника и последовательности
`status`/`connect` зафиксирован в [отчёте проверки](docs/verification/2026-08-29-q2pro-x-live-custom-source.md).
Результаты сборки, проверки готовых архивов и живого Windows-входа приведены
отдельными строками в [rc12 verification](docs/verification/1.0.0-rc12.md).

Windows RC artifacts не подписаны Authenticode. Для каждого публикуемого
архива нужен соседний SHA-256; до широкого распространения должны быть
пройдены все release-gates, указанные в [docs/RELEASE.md](docs/RELEASE.md).
